## Problem
The `<img>` rendered by `LLMNode` for generated images uses `alt="Generated"`. Screen readers read "Generated, image" — it's content-free.

## Why it matters
- Fails WCAG meaningful-alt guidance.
- Users on assistive tech can't tell two generated images apart in their own workflow.

## Suggested fix
Build a more descriptive alt from data the node already has:

```tsx
const alt = systemPrompt
  ? `Generated by ${modelLabel}: ${systemPrompt.slice(0, 80)}`
  : `Image generated by ${modelLabel}`;
```

Truncate so very long prompts don't make alt text unwieldy.

## Acceptance criteria
- [ ] Alt text includes the model and a snippet of the prompt or input description.
- [ ] No regression on text-only LLM output (which has no `<img>` to begin with).
